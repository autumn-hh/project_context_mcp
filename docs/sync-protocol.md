# P1 增量同步协议与操作

## 身份与日志

每个同步空间有稳定 syncId，本地 projectId 通过显式配置绑定。设备 ID 保存在本机共享存储，不进入 P0 快照；新机器生成新 ID。远程目标凭据代表单用户同步空间访问权，不引入虚构的账号服务。

同步启用时在项目库内创建独立日志/头版本表和 SQL 触发器，既有业务写入与事件追加在同一 SQLite 事务提交。未启用项目不额外产生同步事件。每个事件有随机全局 ID、设备 ID、实体类型与 ID、父事件集合、逻辑版本、记录快照或墓碑。事件使用因果父集合，不信任机器墙钟排序。

初次启用将当前知识作为基线事件；日志含来源、候选、任务与请求回执。来源摘录/代码索引不进入事件。跨机来源 ID 置空，目标重新绑定。任务历史以独立事件身份同步，接收方分配本地 sequence，避免两个自增序列冲突。

## 合并

父事件未到时暂存事件，等待依赖；重复 ID 同内容幂等，不同内容拒绝。实体头集合表示并发分支；新事件只淘汰其因果祖先，旧事件不能覆盖后继。非冲突使用原记录，冲突保存全部版本并按逻辑版本与事件 ID 形成确定性展示；并发删除优先保留删除状态，活跃记忆冲突不直接进入正式上下文。

决策 supersede 是显式引用，所有版本保留。任务 completed/cancelled 并发产生冲突，不通过设备时钟假装存在先后。人工选择会创建以全部冲突头为父的新事件，随后所有副本收敛。墓碑与事件首版不自动清理；未来基于设备确认水位/过期设备重新导入快照做压缩。

## 传输

事件批次加密后写为不可变 S3 对象；通过受前缀限制的 ListObjectsV2 获取批次，持久化已接收对象。无网络时本地事务正常提交，待推送事件留在本地。响应丢失通过不可变键与摘要校验确认；下载批次认证成功再进行单库事务导入。

项目与 registry 不提供跨库原子快照。规则首版只同步当前项目的 project/module/task 作用域；全局/工作区规则保留本地，可用 P0 显式备份迁移。registry 的事务 outbox 在写入时捕获因果父集合，项目库按回执幂等接收；投影回 registry 时持写锁并先消费排队写入，不丢失网络等待期间的规则修改。两库失败后可以重新执行推拉，不伪装为跨库原子事务。

## 配置与使用

两台机器配置相同存储目标与备份口令，使用独立本机 registry 和设备身份。相同 syncId 表示同一同步空间，不同源码目录的本地 projectId 可以不同。

```powershell
node dist/cli.js sync configure <local-project-id> --space my-project --remote personal
node dist/cli.js sync status <local-project-id>
node dist/cli.js sync push <local-project-id>
node dist/cli.js sync pull <local-project-id>
node dist/cli.js sync conflicts <local-project-id>
node dist/cli.js sync resolve <local-project-id> --table memories --entity <memory-id> --choose <event-id>
```

新增 MCP：sync_status、sync_push、sync_pull、sync_conflicts、sync_resolve。配置由本地 CLI 显式完成。工作台远程备份页含同步状态、推拉和冲突版本选择。网络不通时本地写入与队列持久化；当前显式推拉，不自动后台轮询。界面「本地队列已处理」不保证远端没有刚出现的新事件。

首版限制：单批最多1000事件/8MiB，单次push最多100批；pull最多100页、每页1000对象。依赖缺失事件保留等待，不应用残缺关系。所有事件和墓碑保留，不做压缩；完整历史较大时需评估存储与首次拉取成本。默认知识包不会复制设备/同步队列；克隆已启用同步的整库到其他设备会拒绝身份冲突，应用知识快照初始化。

项目规则在不同本地项目之间发生同 ID 冲突时拒绝覆盖；这是显式绑定保护，不能通过共享规则绕过作用域。S3凭据和共同口令是首版单用户访问边界；团队成员权限由P2服务单独提供，不能仅靠syncId隔离拥有同一bucket凭据的人。

## 验收

双独立目录模拟设备：首次配对、双向修改、重复、乱序、依赖晚到、并发/删除/终态冲突、重启、断网、同事件 ID 内容冲突、task requestId 冲突、规则作用域。隔离测试与浏览器已验证这些首版路径；真实云端与大规模长期运行尚未验收。
