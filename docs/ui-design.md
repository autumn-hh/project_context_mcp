# 本地工作台界面

工作台保留原生 HTML/CSS/JavaScript，在现有浅色与绿色强调色基础上统一导航、列表、卡片、输入框和弹窗。展示层集中在 `src/ui/workspace-theme.ts`，由本地服务与基础样式一起提供，不加载外部组件或字体。

## 设计参考

实际阅读了 [21st.dev 社区组件](https://21st.dev/community/components)、[Origin UI 步骤条](https://21st.dev/@originui/components/stepper/with-inline-titles-and-descriptions) 和 [ReUI 按钮式 Tabs](https://21st.dev/@sean0205/components/tabs/button)。借鉴其紧凑步骤、分段导航和状态层级，未复制组件源码，也未引入 React/Tailwind 依赖。

- 任务列表集中展示目标、状态、摘要、项目与更新时间；长目标可在详情查看完整内容。
- 总数、页容量和翻页留在任务队列底部，桌面列表独立滚动；窄屏队列横向滚动，详情在下方。
- 详情以任务目标为主标题，优先展示最新进展、接下来、已完成与阻塞；统计为紧凑摘要。阶段、创建时间和任务 ID 收纳在“任务阶段与记录信息”。阶段来自检查点，不代表后台执行，也不代表验证通过。
- 画像、规则、上下文采用一致的卡片与间距。窄屏保留规则项目筛选和历史开关，导航提供选中语义与键盘焦点样式。

## 本次验证

在隔离数据中检查 1440、640、390px 四个页面，未发现文档横向溢出；实际查看长任务名、上下文结果、规则列表及编辑器、画像维护区、升级弹窗截图。验证 10 条页容量和下一页，无浏览器控制台错误。升级弹窗只检查展示与关闭，本次不再次执行数据库升级；代码关系图的复杂节点布局、原生浏览器 200% 缩放未单独验证。统计卡片检查现有测试数据，未覆盖任意极大数字。

## 内容层级与空间调整

- 任务搜索和筛选归属左侧队列，收起的筛选仍显示当前条件；部分项目不可读取时保留简短提示，原因可展开。桌面顶部导航与工具栏合计约 122px。
- 项目画像分为项目概览、代码关系、索引与存储。概览先展示进行中任务、近期记忆与代码构成；维护页集中保留索引、监听、升级、清理、权重和过滤设置。关系与维护模式收起概览统计，返回概览可恢复查看。
- 规则页缩窄辅助栏，扩大正文编辑区，可选背景字段保持紧凑；上下文页桌面左侧输入、右侧结果，手机改为上下排列。
- 通用弹窗限制在可用视口内并允许滚动，操作按钮可换行。图关系画布使用视口高度，手机隐藏节点详情不再撑大滚动区域。
- UI 约束按用户要求保存为 MCP 个人级全局记忆（标题“全局 UI 开发与验收：主体突出、空间分配及分页归属”）；未创建或修改 AGENTS.md。

追加验证：1440、980、640、390px 四页面无文档横向溢出，检查 980×560 短视口规则编辑器；隔离环境完成状态筛选、10条分页、规则创建保存、索引入口及升级弹窗打开/关闭。关系图使用小型样例，复杂大图与原生200%缩放仍未单独覆盖。类型检查、构建及8项UI/API测试通过。

## 动态流水线与失效登记

任务详情默认展示重新绘制的图标轨道流水线，动画仅表达检查点记录阶段；完成、取消和阻塞停止流动，减少动态效果设置关闭动画。原有任务、历史记录不删除。

画像读取到数据库缺失时，展示修正项目路径和移除失效登记入口。移除使用应用内确认，不触碰源码或备份；服务器复核数据库及辅助文件、迁移与索引状态。只在隔离数据中验证确认取消、移除和列表刷新，实际失效项目由用户自行确认。

## 任务页启动与大内容

启动只读取项目清单和轻量任务摘要，个人规则及路径找回延后至相关页面；每次任务查询只打开所需项目，并检查库身份。列表与详情分离，缓存以任务事件版本、更新时间及摘要等失效；快速切换取消过时详情请求。完整 MCP/CLI 查询不改变。

完成事项、文件、验证和风险明细每页30条，列表内部滚动，分页在对应明细底部。超过2000字符的单项支持展开全文，历史记录展开后创建正文。明细翻页或全文展开时显示“明细阅读中”，暂停自动刷新；手动刷新恢复。所有数据仍保留，首次选中仍会读取一条完整检查点；历史每页快照仍全量传输，数据库摘要搜索仍有JSON解析成本。

本轮以5000条完成事项+1000个文件的隔离任务检查桌面/390px、连续自动刷新无详情请求、外部检查点更新后刷新、快速切换、规则延迟加载及历史展开；类型构建和165项测试通过。合成性能数字见补丁说明，不能作为远端故障修复证明。

目录推荐根因修复后，升级预览在独立 worker 读取与计算，同项目请求去重，同时只运行一个预览、最多接受8个未完成项目请求。统计按文件祖先目录累计，保留原来的保守推荐语义。实际浏览器使用30,006文件/20,008目录隔离数据，检查桌面与390px弹窗、推荐勾选、搜索、10/20条分页和关闭；仅预览，未在真实项目执行升级。最新全量回归为23文件174项通过。
